# ShopNow — Projeto acadêmico de e-commerce

Projeto desenvolvido por Rodrigo Gomes com HTML5, CSS3 e JavaScript, inspirado no arquivo de referência do Projeto Amazon fornecido no curso Figma Turbo.

## Funcionalidades
- Layout responsivo para desktop, tablet e celular.
- Catálogo de produtos com imagens extraídas do arquivo Figma fornecido.
- Pesquisa por nome e categoria.
- Filtros por departamento e ordenação por preço.
- Carrinho com inclusão, remoção e alteração de quantidade.
- Favoritos, feedback visual e formulário demonstrativo de newsletter.
- Aviso explícito de que checkout e newsletter são demonstrações, sem transação real.

## Publicação no GitHub Pages
1. Crie um repositório público chamado `rodrigo-gomes-shopnow` (o nome e sobrenome ficam no endereço do projeto).
2. Envie todos os arquivos desta pasta para a raiz do repositório.
3. Em Settings → Pages, selecione `Deploy from a branch`, branch `main` e pasta `/ (root)` e salve.
4. Aguarde a publicação e teste o endereço em janela anônima.

O endereço ficará no formato `https://SEU-USUARIO.github.io/rodrigo-gomes-shopnow/`. Assim, o caminho da aplicação contém seu nome e sobrenome, mesmo que seu nome de usuário do GitHub seja diferente.

> Projeto acadêmico demonstrativo. Não representa a loja oficial Amazon nem processa pagamentos.
